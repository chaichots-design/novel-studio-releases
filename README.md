# ห้องเขียนนิยาย: ไฟล์อัปเดต

ที่เก็บนี้มีแค่ไฟล์อัปเดตของโปรแกรม "ห้องเขียนนิยาย" กับ `latest.json` ที่บอกรุ่นล่าสุด
โปรแกรมที่ติดตั้งไว้จะเช็กไฟล์นี้เอง แล้วให้กด "อัปเดตเลย" ในโปรแกรม (ตรวจขนาดและ SHA-256 ก่อนเปิด)

ไฟล์ `novel-studio-<รุ่น>.exe` ใช้อัปเดตเครื่องที่ติดตั้งไว้แล้วเท่านั้น งานเขียนและบัญชีอยู่ครบ
